Team sync — how it works

Stars ★, notes, and dismissals on this dashboard are shared with the whole team. They're stored in a small file that lives alongside this page on GitHub — there's no separate account or app. (What you've read is personal and stays on your own computer.)

Just browsing?

Nothing to set up. You already see the team's stars and notes. You can star and write notes too — they'll be remembered in this browser and shared once a save key is added.

Want your changes to save for the whole team?

You need a one-time "save key" from GitHub (free account required). It takes about two minutes:

  1. Sign in at github.com, click your photo (top-right) → Settings.
  2. Scroll to Developer settings (bottom of the left menu) → Personal access tokens → Fine-grained tokens → Generate new token.
  3. Name it Policy Watch. Set expiration to 90 days (you'll repeat this when it expires).
  4. Under Repository access choose Only select repositories and pick relay-policy-dashboard.
  5. Under Permissions → Repository permissions, set Contents to Read and write. Leave everything else alone.
  6. Click Generate token and copy the long code that starts with github_pat_.
  7. Paste it below, add your name, and click Save. Done — your stars and notes now save for everyone.
Heads-up: this dashboard's GitHub home is public, so notes are visible to anyone who finds it — keep them operational ("we should comment on this"), never confidential. Your save key is stored only in this browser and can only touch this one dashboard.
